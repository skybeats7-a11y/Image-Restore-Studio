# Image Restore Studio v0.4 — Intel-only

The application is packaged as a standalone macOS .pkg. It uses a compatible Python/Pillow-based editor and **bundles** the official macOS Real-ESRGAN NCNN/Vulkan executable (v0.2.5.0 / 20220424) with the *realesrgan-x4plus* photo model.

## What changed
- Readable dark Mac controls using Tk labels instead of Aqua buttons that override text/background colours
- Scrollable left controls, so settings remain accessible on smaller screens
- Stable **same-size** original/processed comparison
- Genuine model-based 4× AI upscaling; 2× generated by downsampling 4× model output and 8× by Lanczos enlargement of a 4× AI pass
- Clear error message when the AI executable cannot run on the current Mac/GPU
- CPU-only conventional resize remains explicitly identified as **not AI**
- Basic mask repair only; full generative inpainting not yet provided

## Hardware constraints
Intel macOS version compatibility and GPU/Vulkan availability are **not verified by the hosted build**. The portable engine uses Vulkan via MoltenVK and may not work on older integrated Intel GPUs or High Sierra. Upscayl's current macOS requirements are macOS 12+, but the 2022 portable Real-ESRGAN engine may be different. Do not assume success until tested on target hardware.

## Build and download
GitHub Actions > **Build Intel standalone installer** > latest successful run > Artifacts > **Image-Restore-Studio-Intel-0.4**. Extract the downloaded artefact ZIP and install the contained PKG.

## Diagnostics
If the application fails to start, read `~/Library/Logs/Image Restore Studio/startup.log`. If image processing fails, capture the error dialogue, especially any Vulkan or MoltenVK output. The PKG is unsigned for Developer ID distribution and is **not notarised** (application bundle receives only ad-hoc signing).

AI model source: https://github.com/xinntao/Real-ESRGAN/releases/tag/v0.2.5.0

No watermark repair can reconstruct guaranteed original image content covered by a mark.
